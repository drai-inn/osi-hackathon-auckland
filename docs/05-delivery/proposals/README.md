# Proposals

Contributions offered to the programme that are not yet in scope, reviewed against what we have
already committed to.

One file each. Every one ends with a recommendation — **accept**, **accept narrowly**, **defer**, or
**decline** — and names the decision point that settles it. A proposal with no recommendation is not
a review, it is a summary.

Accepted proposals leave here: the substance moves into the work package, stage page or activity it
belongs to, and anything that changes scope or a methodological commitment gets an
[ADR](../../adr/). The file stays as the record of what was considered.
