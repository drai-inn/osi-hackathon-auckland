# Working sessions

What was built, what was decided, and what was rejected — dated, one file per session.

**This is the only place in the repo that carries the evolution of our thinking.** Everywhere else
tracks the current state: the README, the narrative and the outreach copy say what we believe now,
not what we used to believe. Strikethroughs and "we originally thought" belong here instead.

Useful when you join late and want to know why something looks the way it does, or when a decision
gets reopened and nobody remembers what ruled out the alternative.

Not a changelog. `git log` is the changelog. This is the reasoning that does not survive in a diff.

**Formal decisions get an [ADR](../../adr/), not a session entry.** If something here changes scope,
an interface, or a methodological commitment, it needs a numbered record of its own — the session
file just says when and why it came up.
